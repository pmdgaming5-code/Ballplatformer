# BallPlatformer

An original Android 2D physics platformer inspired by the accessible feel of ball-based platform games.

## Included in 1.0.0
- 24 playable levels across 6 visual/gameplay worlds
- Ball physics with acceleration, friction, coyote time and jump buffering
- Touch controls for landscape phones and tablets
- Moving platforms, springs, spikes and checkpoints
- 3 enemy behaviors
- Boss encounter on every 4th level, including final boss
- Level select with progression persistence
- Gem collection and lifetime gem counter
- Pause/restart/level select flow
- Procedural particles, lighting-like shading, parallax backgrounds and vector-only rendering
- Procedural sound effects and lightweight looping music; no third-party runtime assets required
- GitHub Actions Android build

## Build

Requires JDK 17 and the Android SDK with API 36. The included GitHub Actions workflow builds a debug APK automatically.

The project intentionally avoids external runtime dependencies so gameplay remains deterministic and lightweight.

## Controls

- Left / Right: roll
- Up: jump
- Top-right pause button: pause
